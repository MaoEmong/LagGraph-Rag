## 2. 핵심 변경 요약

### 2.1 하이브리드 검색
- Docstore에 FTS5 인덱스 저장
- retrieve 단계에서 Dense + Sparse 병합
- 결과 병합 시 rank 기반 hybrid_score 반영

### 2.2 Parent 확장
- parent_id 기준으로 동일 문서 청크 확장
- 재검색 시 문맥 보강 효과 확보

### 2.3 로컬 리랭커
- `sentence-transformers` 기반 Cross-Encoder 적용
- `RERANKER_MODEL=cross-encoder`로 활성화

### 2.4 근거 기반 응답 제한
- 컨텍스트/DB 결과가 없으면 기본 메시지 반환
- 추측 기반 답변 차단

### 2.5 재질의(re-query)
- 근거 부족 시 검색용 쿼리 재생성 후 재검색
- 조건 정교화:
  - citations < requery_min_citations
  - docs < requery_min_docs
  - answer가 no_context_message일 경우
