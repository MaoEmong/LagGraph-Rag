# ask34.md — 작업일지 (상세)

- 날짜: 2026-01-30
- 작업 주제: reranker auto 임계값 스윕 재실행 (재인제스트 후)
- 목표:
  - docs 재인제스트 완료 상태에서 distance 기반 트리거율 측정
  - 임계값 후보 범위를 좁히기 위한 추가 스윕 수행

- 실행 1: 기본 구간 (0.2~0.4)
  - 명령: reranker_sweep.py --thresholds 0.2,0.25,0.3,0.35,0.4
  - 결과 요약:
    - best_distance 분포: min 0.5185 / p50 0.6106 / p75 0.6617 / p90 0.6620 / max 0.7204 / mean 0.6224
    - 트리거율: 전 구간 100% (distance 기준)

- 실행 2: 상향 구간 (0.5~0.7)
  - 명령: reranker_sweep.py --thresholds 0.5,0.55,0.6,0.65,0.7
  - 결과 요약:
    - 0.5: 100%
    - 0.55: 90%
    - 0.6: 80%
    - 0.65: 40%
    - 0.7: 10%

- 해석:
  - 현재 데이터 분포에서 임계값 0.6 전후가 reranker 트리거율의 전환점
  - 0.65 이상은 reranker가 과소 동작할 가능성

- 다음 작업 제안:
  - 목표 트리거율을 50~80%로 잡는다면 임계값 후보는 0.6~0.65 구간
  - 추가 세분화 스윕(0.60, 0.62, 0.64, 0.66) 권장
  - 선택한 값으로 RERANKER_DISTANCE_THRESHOLD 기본값 업데이트 여부 결정
