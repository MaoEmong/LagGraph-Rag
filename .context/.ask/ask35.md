# ask35.md — 작업일지 (상세)

- 날짜: 2026-01-30
- 작업 주제: reranker auto 임계값 세분화 스윕 (0.60~0.66)
- 목표:
  - 전환 구간에서의 트리거율 변화를 세밀하게 확인

- 실행:
  - 명령: reranker_sweep.py --thresholds 0.60,0.62,0.64,0.66
  - 결과 요약:
    - 0.60 → 80%
    - 0.62 → 40%
    - 0.64 → 40%
    - 0.66 → 30%

- 해석:
  - 0.60에서 0.62로 넘어가며 트리거율이 급격히 감소
  - 현재 데이터 분포 기준, 목표 트리거율 50~80%라면 0.60이 가장 적합

- 다음 작업 제안:
  - RERANKER_DISTANCE_THRESHOLD 기본값을 0.60으로 조정
  - 조정 후 E2E 질의 테스트로 품질/지연 영향 확인
