## 3) README.md 변경 사항

### 3.1 환경설정 절차 개선

- 기존: `.env` 직접 생성 안내
- 변경: `.env.example` 복사 후 편집
  - `Copy-Item .env.example .env`
  - `notepad .env`

의도:
- 초기 설정 누락 방지
- 팀원/다른 환경에서 동일한 템플릿 재사용

### 3.2 웹 진입점 명시

- 빠른 시작에 `/web` 접속 단계 추가
- 주요 기능 목록에 웹 클라이언트(`/web`) 명시

### 3.3 이미지 OCR 지원 범위 명시

추가 내용:
- 지원 이미지 확장자(`png/jpg/jpeg/webp/bmp/tif/tiff`)
- 동작 방식:
  - 이미지 자체 검색이 아니라 OCR 추출 텍스트를 인제스트해서 RAG 검색
- 필수 조건:
  - `OCR_ENABLED=true`
  - Tesseract 설치

## 4) OPERATIONS.md 정리

기존 문제:
- 문서 내 한글 인코딩 깨짐(가독성 저하, 유지보수 어려움)

조치:
- `OPERATIONS.md`를 UTF-8 기준으로 전면 재작성
- 현재 프로젝트 운영에 필요한 최소/핵심만 남겨 간결화

구성:
1) 서버 운영(start/stop/restart/status)
2) 헬스체크
3) 웹/API 문서 주소
4) 핵심 API 샘플(`/ingest`, `/chat`, `/threads/reset`)
5) OCR 운영 메모(조건/지원 확장자/주의점)
6) 중복 인제스트 정책
7) E2E 배치 러너 예시
8) 리포트 분석/경고 게이트 예시
